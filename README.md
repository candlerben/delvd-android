# Delvd for Android

Discover. Eat. Support Local. The app for independent food spots in Sunderland: https://delvd.co.uk

## Install

Download the newest version: https://github.com/candlerben/delvd-android/releases/latest/download/Delvd.apk

1. Open the link on your Android phone and download the file.
2. Open the downloaded file.
3. If Android asks, allow "Install unknown apps" for your browser.
4. Tap Install.

When a new version is ready, the app shows a banner. Tap it, or open the same link again.

This page holds the app file only.
